# Heuristic test data

Generated by `heuristic_data.py`. Do not edit by hand; rerun the generator.
Each file uses the tasks.csv format, has 8 to 12 tasks, and needs at most 2 workers
per task (capacity 2). Each file has its own `random.Random(seed)`.
Durations are 1 to 5 days; about 1 task in 5 needs 2 workers.

## Generation rules

- **wide**: T01 is the only root; the middle tasks all depend on T01 (wide fan-out); the last task joins every middle task.
- **deep**: A chain: each task depends on the previous one; about one task in three also depends on a task two or three steps back.
- **mixed**: Three layers of similar size; each task depends on 1 to 2 random tasks of the previous layer; layer 1 has no prerequisites.
